## 🚀 How to Start the System

### 1. Start Backend Server

```bash
cd backend
npm run start
```

Server will run on: `http://localhost:5000`

### 2. Start Frontend Application

```bash
cd frontend
npm run dev
```

Application will run on: `http://localhost:5173`

## 🎯 Quick Navigation

### From Employee Dashboard:

- **Profile** → View/edit personal information
- **Attendance** → Check in/out and view history
- **Leave** → Apply for leave and track status
- **Payroll** → View salary structure and history

### From Admin Dashboard:

- **View All Employees** → Complete employee directory
- **Pending Requests** → Leave approval panel
- **Employee Management** → Detailed employee profiles
